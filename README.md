# 🛒 Shoe Store CRM Backend API

Dự án Backend hệ thống Quản lý Quan hệ Khách hàng (CRM) và Kho hàng dành cho cửa hàng giày, được xây dựng theo mô hình phân tầng (Repository - Service - Controller) với Node.js, Express, và Prisma ORM.

---

## 🚀 Công nghệ sử dụng
* **Runtime:** Node.js (ESM Modules)
* **Framework:** Express.js
* **Database & ORM:** PostgreSQL (Neon), Prisma ORM
* **Authentication / Security:** JWT (JSON Web Tokens), Bcryptjs
